# Telegram Conversation Studies

A readable React recreation of the Telegram Web K conversation interface.

The runnable application lives in [react-tweb](./react-tweb/README.md).
It uses simulated conversations and stores changes on the current device.

```sh
cd react-tweb
pnpm install
pnpm dev
```

Start learning with the [source guide](./react-tweb/docs/source-guide.md).
